# SNORDIAN's Simple H5P Stats

## Install/Usage
Install Simple H5P Stats from the [Wordpress Plugin directory](https://wordpress.org/plugins/snordians-simple-h5p-stats/) or via your Wordpress instance and activate it. Done.
