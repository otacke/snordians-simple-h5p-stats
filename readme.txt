Simple solution to track hits on H5P content.

== Description ==
Tracks how many times H5P content is accessed, with optional unique visitor deduplication.

== Installation ==
Install Simple H5P Stats from the Wordpress Plugin directory or via your Wordpress instance and activate it. Done.
